# ERROR State

## Context
Terminal error state capturing failure diagnostics, environment discrepancies, or unrecoverable issues.

## Instructions
1. Identify the root cause of the failure (e.g. missing tools, failed export script, invalid input).
2. Write a diagnostic summary to `.docs/resume-manager-errors.md`.
3. Provide clear remediation guidance for the user.

## Signal
Terminal state. No further signals.
