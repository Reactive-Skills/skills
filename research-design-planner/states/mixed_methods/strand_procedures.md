# Strand procedures

Use the selected design: convergent, explanatory sequential, exploratory sequential, or complex.
Plan each strand's questions, sampling, measures or data sources, collection, analysis, and timing.
State which strand has priority if there is one.
Explain how one strand informs the other in a sequential design.
Do not call two parallel methods mixed methods unless the plan integrates them.
Continue to integration, clarification, or synthesis.

## Signals
Emit `CONTINUE_TO_INTEGRATION`, `ASK_CLARIFY`, or `SYNTHESIZE`.

## Atomic gate
- [ ] Make sequence and priority explicit.
- [ ] Identify the intended integration point.
